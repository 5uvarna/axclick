FAQ

Questions

Why did you build axclick?

For myself. I wanted to click around my Mac without reaching for the trackpad, but the apps that did it well cost more than I wanted to pay. So I built a free one, made it open source, and kept every feature free. A small optional license helps cover the cost of keeping it going.

Why does macOS warn me about the download?

Apple charges developers $99 a year to notarize apps, which is what removes that warning. axclick is a hobby project, so it isn't notarized yet. If it makes $99, notarization is the first thing I'll pay for. Until then, the app is signed, its full source is on GitHub, and the one-line installer skips the warning entirely.

Why does it need Accessibility access?

That's how macOS lets an app see and press buttons in other apps. axclick only reads the app in front, only while labels show, and never sends what you do anywhere. The only network request, in the download, is checking a license key with Gumroad once.

Which apps does it work with?

Most apps: Safari, Chrome, Electron apps like VS Code and Slack, Finder, System Settings, dialogs and menu bar icons. For apps that draw their own UI, like some games, grid mode clicks anywhere.

Is it really free?

Yes, every feature, with no time limit. The Homebrew version never reminds you. The download shows a small reminder every 100 uses, at most once a week, and never steals focus. A $9.99 one-time license removes it.

How many Macs can I use a license on?

You can activate a license up to 10 times, across all your Macs. If you run out, reply to your Gumroad receipt and we'll sort it out.

Can I change the shortcuts?

Yes. Click the axe in the menu bar, choose Settings…, and record new ones. You can turn on launch at login there too.

What if I don't know the label?

Press / in click mode and type the text on the button instead, like “save”. Tab moves to the next match.
