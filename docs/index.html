Features

Your keyboard, everywhere.

Everything you'd reach for the mouse to do, from a few keys.

⌖

Precise clicks

Elements come from the macOS Accessibility API, so axclick presses the element itself instead of guessing at screen coordinates.

A

Home-row labels

Labels start on A S D F J K L, so the most common ones are two quick keystrokes.

/

Search by text

Press / and type the words on a button, like “save” or “sign in”. Return clicks the best match.

↕

Scroll mode

Press ⌘⇧J and scroll with j k, half a page with d u, or jump to the top or bottom with g G.

◉

Menu bar icons

Wi-Fi, Bluetooth, sound, battery, Control Center and other apps' menu bar icons get labels too.

#

Grid for everything else

Games, canvases and remote desktops don't expose buttons. Press Space, then three keys on a Q–V grid click anywhere.

◎

Keeps your focus

The app in front stays active while labels show, so open menus and popovers stay open.

▤

Works where you work

Chrome, Safari, Electron apps like VS Code and Slack, Finder, menus, dialogs and the menu bar.

⇧

Right-click and ⌘-click

Hold Shift on the last letter to right-click, or ⌘ to open a link in a new tab.

✦

Small and private

Plain Swift, no dependencies, no tracking. It only reads the front app while labels show, and the only network request is checking a license key once.

Installing

The easy way in.

axclick isn't notarized by Apple yet, so macOS warns about the download. One command skips that.

curl -fsSL https://5uvarna.github.io/axclick/install.sh | bash

Paste it into Terminal (in Applications → Utilities) and press Return. It downloads the same app, checks its signature, moves it to Applications and opens it. Run it again any time to update. Read the script

FAQ

Questions

macOS says it can't check axclick for malware. Is it safe?

That message appears because the download isn't notarized by Apple yet, not because anything was found. axclick is signed, and its full source is on GitHub. To skip the message, install with one command, or follow the four steps to open the download. Homebrew also builds it from source if you prefer.

Why does it need Accessibility access?

That's how macOS lets an app see the buttons and links in other apps and press them. axclick only reads the app in front, only while labels are showing. It never sends anything about what you do anywhere: the only network request, in the downloadable app, is checking your license key with Gumroad once. The source is on GitHub if you want to check.

Which apps does it work with?

Most apps that support macOS accessibility, including Safari, Chrome, Electron apps like VS Code and Slack, Finder, System Settings and the menu bar. Apps that draw their own UI without accessibility info, like some games, show few or no labels. For those, grid mode lets you click anywhere on any screen.

Is it really free?

Yes, every feature, with no time limit. Homebrew and source builds have no reminders at all. The ready-to-run download is free too, with a small reminder after every 100 uses, at most once a week. It never interrupts a click and never steals focus. A $9.99 one-time license removes it and pays for further work.

How many Macs can I use a license on?

You can activate a license up to 10 times, across all your Macs. Activating again, for example after reinstalling, counts toward the limit. If you run out, reply to your Gumroad receipt and we'll sort it out.

Can I change the shortcuts?

Yes. Click the axe icon in the menu bar, choose Settings…, and type a new shortcut for labels or scroll mode. You can also turn on launch at login there.

What if I don't know the label?

Press / while labels show and type the text on the button instead, like “save”. Exact matches come first, and Tab moves to the next one.
