Why axclick

Precise clicks

Elements come from the macOS Accessibility API, so axclick presses the element itself instead of guessing at screen coordinates.

Home-row labels

Labels start on A S D F J K L, so the most common ones are two quick keystrokes.

Search by text

Press / and type the words on a button, like “save” or “sign in”. Return clicks the best match.

Scroll mode

Press ⌘⇧J and scroll with j k, half a page with d u, or jump to the top or bottom with g G.

Menu bar icons

Wi-Fi, Bluetooth, sound, battery, Control Center and other apps' menu bar icons get labels too.

Grid for everything else

Games, canvases and remote desktops don't expose buttons. Press Space, then three keys on a Q W E R / A S D F / Z X C V grid click anywhere.

Keeps your focus

The app in front stays active while labels show, so open menus and popovers stay open.

Works where you work

Chrome, Electron apps like VS Code, Finder, menus, dialogs and the menu bar.

Right-click and ⌘-click

Hold Shift on the last letter to right-click, or ⌘ to open a link in a new tab.

Small and private

Plain Swift, no dependencies, no network connections. It only reads the front app while labels show.

Questions

Why does it need Accessibility access?

That's how macOS lets an app see the buttons and links in other apps and press them. axclick only reads the app in front, only while labels are showing, and makes no network connections. The source is on GitHub if you want to check.

Which apps does it work with?

Most apps that support macOS accessibility, including Safari, Chrome, Electron apps like VS Code and Slack, Finder, System Settings and the menu bar. Apps that draw their own UI without accessibility info, like some games, show few or no labels. For those, grid mode lets you click anywhere on any screen.

Is it really free?

Yes. Install it with Homebrew or build it from source for free. A paid, ready-to-run download is planned for people who'd rather not use developer tools, and it pays for further work.

Can I change the shortcuts?

Yes. Click the axe icon in the menu bar, choose Settings…, and type a new shortcut for labels or scroll mode. You can also turn on launch at login there.

What if I don't know the label?

Press / while labels show and type the text on the button instead, like “save”. Exact matches come first, and Tab moves to the next one.
